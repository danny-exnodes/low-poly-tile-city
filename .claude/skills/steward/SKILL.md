# Steward

## Công cụ
- Không có `gh`. Dùng MCP `mcp__github__*`: `create_pull_request`, `pull_request_read` (`get_check_runs`, `get_status`), `merge_pull_request`, `issue_write`, `actions_list`, `get_job_logs`.
- Theo dõi PR bằng `subscribe_pr_activity`; không poll bằng `sleep`.

## Push
- `git push -u origin <branch>`; lỗi mạng thì thử lại sau 2 s, 4 s, 8 s, 16 s.
- **Tag:** proxy chặn push tag. Không cần tag tay: workflow `deploy-pages.yml` (job `release`) tự tạo tag `v<version>` + GitHub Release kèm zip bản web khi `version:` trong `pubspec.yaml` chưa có release.

## PR
- Tiêu đề: `vX.Y.Z: <tóm tắt>` (tiếng Anh).
- Body tiếng Việt, nhóm theo vùng thay đổi, có `Closes #N` / `Refs #N`.
- Mục **Kiểm tra**: lệnh đã chạy, số bench/perf trước → sau, phần nào chỉ kiểm trên swiftshader.
- Kết thúc body bằng dòng attribution mà session yêu cầu (ví dụ `🤖 Generated with [Claude Code](https://claude.com/claude-code)`).

## Comment GitHub
Chỉ comment khi cần; kết thúc bằng footer `---\n_Generated by [Claude Code](https://claude.ai/code)_`.

## CI (`.github/workflows/deploy-pages.yml`)
- Job `build`: `flutter analyze`, `flutter test` (gồm `test/bench_test.dart`), `flutter build web --base-href /<repo>/`.
- Job `deploy` (chỉ push vào `master`): GitHub Pages, environment `github-pages`. Nếu `deploy` fail trong 1 giây không có bước nào: environment không cho nhánh → chủ dự án vào Settings → Environments → github-pages → Deployment branches thêm `master`.
- Job `release` (chỉ push): tag + release theo version.
- Trên PR, `deploy`/`release` bị skip là bình thường.

## Merge
- Khi job `build` = success.
- Head SHA của PR phải bằng `git rev-parse HEAD`, `git status` sạch.
- `merge_pull_request` với `expectedHeadSha`, kiểu merge `merge`.

## CI đỏ
Tái hiện cục bộ (`check.sh`), sửa, push. Không skip/vô hiệu test, không push commit rỗng. Bench đỏ do máy CI chậm: đo lại cục bộ; chỉ nới ngân sách khi TL ghi lý do trong issue.

## Sau merge
- Deploy tự chạy: https://danny-exnodes.github.io/low-poly-tile-city/
- Kiểm release `v<version>` đã có; cập nhật Roadmap #1, đóng issue (PR `Closes` tự đóng).
