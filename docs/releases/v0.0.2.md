## 1. Sản phẩm là gì
Thị trấn low-poly sinh thủ tục chạy trên trình duyệt (Flutter web, renderer tự viết). Xem README.

Đợt góp ý 1 của chủ dự án (Roadmap #1), giữ nguyên đánh số:
1. Khi mở rộng mặt phẳng, chỉ thêm tile đất trống không có nhà cửa → **#3 (xong ở bản này)**
2. Chưa có bộ công cụ tạo/thay đổi công trình trên tile → #7, #8 (v0.0.4)
3. Chưa có hiệu ứng kiến trúc được xây lên từ từ như video → #6 (v0.0.3)
4. Còn khá lag, cần tối ưu → **#4 (xong ở bản này)**
5. Model còn góc cạnh, chưa ra phong cách low-poly → #5 (v0.0.3)

Thêm: thiết lập quy trình nhóm agent theo playbook Tiny Map → **#2 (xong ở bản này)**. Chủ dự án giao toàn quyền chạy hết roadmap.

## 3. Kiến trúc: phần thay đổi
```
City.build ─▶ _board (bảng + vạch đường) + Block × N
Block: objects / trees / spinners / lamps / ground (SceneObject riêng)
City.rebuildBlocks([a, b]) ─▶ thay Block, gỡ object cũ khỏi scene ─▶ _finish():
    gom trees/spinners/lamps, scene.groundObjects, heightmap, updateShadows
City.resize: ô mới = BlockContent(empty); ô bị cắt → _stash[(i,j)] = (hiện tại, gốc)
updateShadows: _ShadowPts (Expando theo Mesh) = mỗi mức y một hình chữ nhật bao;
    monument (sortParts) giữ 8 góc từng part → chiếu theo nắng → hull → tam giác quạt
Mesh.lod (lười) / lodPx; Renderer chọn LOD theo bán kính chiếu (px) × lodScale
Mat.branch: cành cây, shade() trả 0 ngoài mùa đông
Tilt-shift: scene Picture → (blur σ1,4, scale 0,35) toImageSync → drawVertices 2 dải, alpha theo đỉnh, BlendMode.modulate
debug_hook.dart: window.__tileCity.stats()/cmd(json) khi --dart-define=DEBUG_HOOK=true
```
- `scene.groundObjects` thay cho `scene.ground/groundObject`.
- Cây đường phố dùng random riêng theo khối (`seed ^ 0x5bd1e995`) để dựng lại một khối cho kết quả ổn định.
- Thử `--wasm`: Dart render 5,9–10,2 ms so với JS 5,1–5,5 ms → giữ JS.

## 4. Giới hạn đã biết
- Đã biết, chưa sửa:
  - Ánh sáng giữa trưa quá gắt (vỉa hè gần trắng) — thuộc #5.
  - Bóng của nhà hình chữ L là bao lồi (hơi to hơn thực tế) — chấp nhận.
  - Đổi Street trees / Switch trees / Width vẫn dựng lại toàn bộ (~25 ms, chỉ khi thả slider).
  - Số fps trong sandbox là swiftshader; cần thử trên máy thật.

## 5. Môi trường của agent
- Flutter 3.47.8 cài tay vào `/opt/flutter` (lệnh trong skill `developer`).
- Playwright + Chromium swiftshader có sẵn; build có hook: `.claude/skills/qa-visual/scripts/serve.sh <port>`.
- Proxy chặn push tag → CI tạo tag/release. `pkill -f` tự giết shell → dùng `fuser -k <port>/tcp`.
- `toImageSync` trong `flutter_tester` rất chậm → bench tắt tilt-shift.

## 6. Quy trình làm việc đã thống nhất
