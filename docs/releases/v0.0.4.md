## 3. Kiến trúc: phần thay đổi
```
BlockContent.lots: Map<int, LotOverride>   (thay monuments)
LotOverride { style, floors, facade, roof, roofKind, rotSteps, seed, demolished, monument }
Lot.baseRot/baseStyle/baseSeed + getter rot/style/seed/monument/demolished
buildHouse(style, w, d, seed, HouseOptions)  — vẫn rút số ngẫu nhiên theo đúng thứ tự cũ
    → nhà chưa chỉnh giống hệt v0.0.3; RoofKind + _roof() dùng chung
City._origin (Expando) giữ (kind, seed) gốc → resetBlocks khôi phục loại ô
World.mode: ToolMode { view, move, build }; selectedBlock; hover() → outline
World.editLot(l, fn) / setTileKind / tileVariant / clearTile / undo (_Snapshot: thứ tự + bản sao nội dung)
UI: tile_panel.dart (TilePanel, UndoButton), building_panel.dart (BuildingPanel),
    house_panel.dart (HousePanel, MonumentPicker, PanelHeader, LotStatus)
```
- Undo bị xoá khi đổi kích thước bản đồ (snapshot gắn với một kích thước).
- Lô bị phá dỡ chọn được bằng click nền trong chế độ Build (`_lotAt`).
- Hook QA thêm lệnh `mode`, `tile`, `selectTile`, `selectLot`, `edit`, `undo`.

## 4. Giới hạn đã biết
- Xoay 90° chỉ cho lô vuông; lô chữ nhật xoay 180° để công trình không lấn ra ngoài lô.
- Kiểu Apartment/Office chỉ hiện khi lô ≥ 10 m.
- Chỉnh sửa chưa được lưu khi tải lại trang → v0.0.5 (#9).
- Xe chồng nhau trong ngã tư (từ v0.0.3).
