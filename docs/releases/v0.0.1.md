# Low-Poly Tile City v0.0.1: release note và checkpoint

> 27/10/2026 · Commit `7f3edac` (tag `v0.0.1` do CI tạo) · Bản chạy: https://danny-exnodes.github.io/low-poly-tile-city/
>
> Tài liệu này là điểm khôi phục ngữ cảnh: agent mới đọc file này + `CLAUDE.md` là làm tiếp được. Viết bổ sung ở v0.0.2 để mô tả hiện trạng bản đầu tiên.

## 1. Sản phẩm là gì
Ứng dụng Flutter (bản đầu chỉ chạy trên trình duyệt) dựng lại một thị trấn low-poly kiểu "tile city" theo video tham khảo của chủ dự án: bàn cờ các khối nhà, đường phố, cây đổi màu theo mùa, lá rơi theo gió, tilt-shift, panel Settings và panel đổi nhà thành tượng đài.

Yêu cầu của chủ dự án:
1. Build app Flutter "Low-Poly Tile City" giống video; bản đầu cho trình duyệt, chưa cần iOS/Android.
2. Thiết lập GitHub Actions để build và host trên GitHub Pages.
3. Phát hành v0.0.1.

## 2. Tính năng trong v0.0.1
| Nhóm | Tính năng |
| --- | --- |
| Thành phố | 5×5 khối: nhà phố, nhà vườn, chung cư, văn phòng, công viên, quảng trường, hội chợ (vòng quay, đu quay, lều xiếc), nông trại cối xay gió, siêu thị, bệnh viện + bãi trực thăng, sân bóng, nhà thờ |
| Sống động | Xe chạy theo làn và rẽ ở ngã tư; người đi bộ trên vỉa hè |
| Khí quyển | Thanh Light (giờ trong ngày, đèn cửa sổ và đèn đường ban đêm), 4 mùa, bóng đổ trên mặt đất |
| Gió | Tốc độ + la bàn hướng gió; cây lắc; lá/cánh hoa/tuyết rơi và đọng lại; Gust; Leaf devil |
| Tượng đài | 10 công trình (Tokyo Tower … Moai), dựng lên có hiệu ứng; nút Original |
| Công cụ | Width/Depth, mật độ xe/người, cây đường phố, lượng lá, cỡ lá, Switch trees, Move blocks, Reset blocks/houses, Whole map, Tilt-shift |
| Âm thanh | Web Audio: gió, lá, chim, dế, xe; nhạc sinh tự động |
| Hạ tầng | CI build/test, deploy Pages, tự tạo tag + release theo version |

## 3. Kiến trúc
Renderer tự viết trong `lib/engine` (mesh → ánh sáng từng tam giác → sort theo độ sâu → `drawVertices`), thành phố sinh thủ tục trong `lib/world`, UI trong `lib/ui`, âm thanh `lib/audio`.

## 4. Giới hạn đã biết (khi phát hành)
- Mở rộng bản đồ sinh thêm khối đầy nhà (→ #3).
- Lag: kéo Light 34 ms/khung cho bóng, tilt-shift ×3 GPU, đổi chỗ khối dựng lại toàn bộ (→ #4).
- Model góc cạnh, ánh sáng gắt, răng cưa (→ #5); chưa có hiệu ứng xây dần (→ #6); chưa có công cụ xây dựng (→ #7, #8).
